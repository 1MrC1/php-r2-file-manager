# R2 File Manager & Video Backup

A small self-contained PHP app with a one-time web installer:

- **R2 File Manager** (`index.php`) — browse buckets, directories and files from a
  MySQL index (e.g. one filled by a Cloudflare R2/S3 crawler). Breadcrumbs,
  pagination, per-bucket switcher and direct file links.
- **Video Backup** (`links.php`) — a tiny form + list to catalog video backup
  links with tags.

Both pages sit behind an access-key gate and share a single `config.php`
generated by the installer.

## Requirements

- PHP 7.4+ with `mysqli` and `pdo_mysql`
- MySQL 5.7+ / MariaDB 10.3+
- Any web server (Apache, nginx, ...)

## Install

1. Upload or clone this repository into your web space.
2. Open `install.php` in your browser and fill in the form
   (site title, database credentials, access key, first bucket).
3. The installer creates the database if needed, creates the tables,
   seeds the first bucket, and writes `config.php` + `install.lock`.
4. **Delete `install.php`.** While `install.lock` exists the installer
   refuses to run again, but deleting the file is safer.

### Manual install

Copy `config.sample.php` to `config.php`, fill in your values, and create the
tables yourself — the SQL statements are in the `$schema` array in `install.php`.

## Access key

Pages are hidden behind a key: open `https://example.com/index.php?key=YOUR_KEY`
once to start the session, then browse normally. Requests without a valid
session get a blank 404. Change the key any time in `config.php` (`access_key`).

## How the file index works

The file manager only reads MySQL — it never talks to R2/S3 directly. Populate
these tables with your own indexer/crawler:

| Table | One row per | Columns used |
|---|---|---|
| `buckets` | bucket | `bucket_id`, `bucket_name`, `endpoint_url` |
| `directories` | directory | `bucket_id`, `path`, `object_count`, `total_size`, `last_modified` |
| `files` | object | `bucket_id`, `directory_id`, `object_key`, `size`, `last_modified`, `is_active` |

File links point to `custom_domain/object_key` when `custom_domain` is set in
`config.php`, otherwise to the bucket's `endpoint_url/object_key`.

## Files

- `install.php` — one-time web installer (delete after use)
- `bootstrap.php` — loads `config.php`, enforces the access-key gate
- `index.php` — R2 File Manager
- `links.php` — Video Backup form and list
- `config.sample.php` — configuration template

## Security notes

- `config.php`, `.env` and `install.lock` are listed in `.gitignore` — never
  commit real credentials.
- Use a MySQL user limited to this one database.
- The access key is lightweight protection, not full authentication — don't
  expose sensitive data behind it.
